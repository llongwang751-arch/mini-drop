# SRE Agent 故障恢复验收

分别验收 API、任务队列、采集器、分析器、模型供应商、数据库和对象存储；健康检查通过不表示运行中任务可恢复。

## 中断、租约与幂等

在隔离环境于工具执行前后中断 Worker，记录任务租约、恢复耗时及重复副作用。模拟模型超时、检索失败、Agent 离线，要求有界终止与明确降级。重试前验证旧任务是否已产生有效结果。

## 持久化与容量

恢复到独立数据库和对象桶，核对行数、对象 hash 与引用完整性，不能只检查备份文件存在。长期测试记录并发、吞吐、延迟、RSS、磁盘增长与失败率；短期健康检查不应外推长期容量。所有演练保留原生产卷。
