# Linux I/O wait 诊断

同宿主多个实例同时出现 iowait 更支持共享块设备或宿主机争抢，但仍需设备延迟、队列和工作负载方向排除共同流量上涨。虚拟机磁盘还可能在物理宿主层共享设备。

安全探针优先级：sys_metrics（R1）→ 设备统计 → 单次 eBPF I/O 延迟（R2）。

## 同节点、同主机与共享设备

same-host、same-node、co-located / colocated 描述部署位置。只有确认目标与邻居映射到同一块设备或共享宿主资源，位置关系才是争用调查线索。设备队列、目标等待与邻居负载必须在同一窗口核对；共同流量上涨、虚拟磁盘映射和设备层限速都是替代解释。

`/sys/block/<dev>/stat` 的 in_flight 计数表示已经交给驱动且未完成的请求，不包含尚未发给驱动的排队请求。请求等待累计值需对采样窗口求差，并与完成数、设备归属和请求延迟一起解释；不能仅凭一个繁忙度计数宣布具体邻居是根因。

来源：[Linux 块层统计官方文档](https://docs.kernel.org/block/stat.html)。同步写的低延迟与反证见 [同步写指南](synchronous_io.md)。
