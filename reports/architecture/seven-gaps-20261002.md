## 保留失败并修复原因

首次七个真机试验为 5/7，随后针对 C++ CPU 和共享配额分别新建独立试验，总计九次。首次两个失败的 case、原始下载与 SHA 均保留，不覆盖、不改分。

C++ CPU 的 perf 采集成功，但运行镜像缺少 binutils/addr2line，源码解析命令失败。补齐正式镜像依赖，使用原始 90,212 字节 perf 文件只读重放，实际解析 952 个样本；新试验同时取得源码行和独立 CPU 窗口。CI 新增真正构建的 Analyzer 工具链镜像测试，验证可执行文件、nm 与 addr2line。工具链格式测试不宣称真实 perf 采样或根因。

共享配额首次已经测到双方活动和节流，却因原始 Linux boot_id 带末尾换行、Analyzer 摘要已去换行而拒绝同一身份。修复仅正规化字符串边缘空白，不降低目标启动身份、cgroup、配额、采样窗口及计数增量检查；使用原始文件重放证明旧验证拒绝、新验证通过，新独立试验再通过。

分析命令失败现在保存经过限长和脱敏的原因及退出码，避免再次只留下 INTERNAL_ERROR。规划按注册合同先取相应信号，不能由模型自称高 value/prior 抢走必要探针，也不会将不受支持的模型假设偷偷改成可通过的假设。
