# Go CPU、堆与阻塞采样选型

按问题选择 profile：CPU 描述执行消耗，heap 描述堆分配视角，block 与 mutex 用于阻塞及锁竞争调查。不要用 CPU 火焰图直接证明等待时间。

## Go goroutine 与锁竞争

先核对 goroutine 栈、阻塞位置与请求延迟的时间窗；大量 goroutine 本身不是泄漏结论。确认目标启用了相应采样，缺少 block 或 mutex 样本可能是未配置。仅通过已授权的目标端点取数，不将 pprof 暴露公网。

## Go 堆增长与修复复测

分别阅读累计分配与仍存活对象，保持采样口径、GC 阶段和工作负载可比。修复后同时观察存活量、分配速率、CPU 与请求延迟，避免把性能转移到另一资源算作成功。
