# Python 采样归因：先检查采样语义

py-spy 的线程栈分布不直接等于进程 CPU 使用率。调查前记录 PID、进程启动时间、Python 版本、采集参数、时间窗和每线程样本数。先用进程 CPU 增量确认计算压力，再用栈寻找代码位置。

## Python 空闲线程、GIL 与非阻塞采样

若多个线程样本数近似相等，且叶帧停在 sleep 或指标发布处，应怀疑空闲判定或线程身份映射。核对宿主机与容器线程 ID，保留原始 speedscope；不要按函数名删除“不喜欢”的样本。--gil 仅观察持有 GIL 的线程，会漏掉释放 GIL 的扩展；--nonblocking 存在读取非原子状态的限制。不同采样模式必须单独标注，不能直接混用分母。

## Python 源码热点与独立验证

同一函数不同执行行可能分散样本，需同时阅读函数和行级统计。只有可解析源码位置、有效样本和同窗进程压力才能支持热点调查；热点仍不自动证明业务回归。相同输入、并发与时长复测，并用吞吐、延迟及错误率确认影响。采集失败不属于反证。
