# ReAct 与 LATS 的可重复比较

实验固定模型、知识快照、工具集合、预算、负载和故障版本。ReAct 与 LATS 都必须执行真实观察循环；单次工具基线不代表 ReAct。

## 真值与评价隔离

注入场景真值只提供给评测器，避免出现在 Agent 提示、RAG 或历史记忆中。顺序交替并重复执行，逐次保存失败、成本、耗时和产物；不能只展示成功轮次。报告门禁 VERIFIED 与真值正确性分别评分。

## 搜索策略与现场时间

线上现场随时间变化，不能像可复位模拟器一样回滚到旧树节点的物理状态。LATS 候选选择应记录观察时间及证据过期；不要用模型自评分代替独立根因判定。先完成无故障负例与几种可稳定复现的故障，再扩大场景。
