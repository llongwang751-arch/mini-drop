## 当前限制

在线 Agent 仅声明 `PROC_CPU`、`PERF_CPU` 两类采集能力。目录中的其他任务类型与已有离线分析代码，不等于这台 Agent 已支持对应现场采集。高级语言/内存/BPF采集、最终独立 helper、partial 故障到界面的真实全链、完整 stage、BOLT 新 toy 工具链验证继续待完成。

入口仍为 HTTP，尚未启用受信任 HTTPS、Secure Cookie 或新的证书轮换。新 Ops、生产 SSE 加密迁移、密钥备份、定时异地复制、完整监控/恢复、多架构运行、HA 以及企业身份源/模型服务真实接入均未随本次上线。

API、Web rc7 和内部网关的实际 Grype 扫描均为 0 Critical / 0 High，各有 3 Medium，API 另有 1 Unknown。Analyzer rc4 仍有 **57 Critical / 329 High 匹配项**，需要逐项核验和修补；匹配数不是独立可利用漏洞数，也没有整批忽略或清零。未上线的 Ops rc4 仍有 61 High。用户要求先行发布，不改变这些检查结果。完整剩余工作见 [CAPABILITY_GAPS.md](../CAPABILITY_GAPS.md)。

## 回滚

应用回滚保留 schema 5、数据库权限、数据卷、新验收任务与制品；不执行数据库降级。原命名镜像和旧配置保留在服务器。先确认没有正在采集/分析的任务，再在维护窗口由运维执行：

```bash
cd /opt/drop/deploy
docker compose --parallel 1 -p drop -f compose.yml -f compose.perf.yml up -d --no-deps --no-build --pull never --wait minio analyzer api web
install -m 0600 -- /opt/drop-releases/20261018.1-limited-r2/rollback/.env /opt/drop/deploy/.env
docker compose -p drop ps
```

显式两个基础 `-f` 选择的是旧版四服务。回滚后再确认健康状态和任务结果可读；不要执行 `compose down -v` 或恢复覆盖现有数据。有限发布协调器的 finalize 是一次性操作；如果替换 `.env` 后写证明失败，应检查现场再回滚，不能盲目重跑。第一次真实回滚已验证旧应用可以在保留 schema 5 的情况下恢复。
