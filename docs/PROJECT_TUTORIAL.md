# Drop 项目教程

配套的 [系统图册](diagrams/drop-system/index.html) 用 14 张图展开模块通信、数据流、采集/分析/AI时序、状态、失败恢复、业务信号与监控；另有全部 16 种现场采集说明和逐步点击链路。可以离线打开，图册不计入下方 22 章正文篇幅。

教程共 22 章。前十章顺着正式工程的一条任务读源码，后十二章亲手接起四种语言的小项目，再把故障、解析、诊断回放和证据检查做成可以运行的实验。正文从具体问题展开，给出中间数据、错误实现的后果、预期结果、排错步骤和作业答案。

当前正文 **102,981 个汉字、285 节、119 个代码块**，汉字统计剔除 fenced code。先前十章约 4.2 万汉字；本轮增加完整实战篇和配套实现。新增内容以可执行的交接和独立验收为依据，不把教学模拟当成生产验收。篇幅、源码摘要及实际检查见 [本轮验证记录](evidence/project-tutorial-practice-20261024/validation.json)，先前十章的记录保留在 [深入版收据](evidence/project-tutorial-20261024/validation.json)。

## 打开教程

只读教程不需要 Docker、业务登录或模型密钥。从项目根目录执行：

```powershell
cd web
npm ci
npm run dev -- --port 4322 --strictPort
```

访问 [第一章](http://127.0.0.1:4322/book/chapter1/) 或 [第 11 章实战起点](http://127.0.0.1:4322/book/chapter11/)。4321 留给参考教程，4322 是本项目建议端口。依赖已按锁文件安装时，可省略 `npm ci`。页面有全书目录、本章目录、复制代码、字号、深浅色、专注阅读、移动目录和打印样式。

普通章节不请求业务 API、不采集、不调用模型。实战工作台 `/book/workbench` 需要先启动独立的 4330 教学 API，点击“连接本地服务”才读取任务；打开工作台本身也不会自动请求。Vite 的 `/mini-api` 代理仅接这条本地教学链。完整正式环境另见 [本地开发](LOCAL_DEVELOPMENT.md)。

## 配套代码怎样运行

完整命令见 [实作总入口](../tutorials/README.md) 与 [Mini Drop README](../tutorials/mini-drop/README.md)。小项目只依赖 C++17 编译器、Go 1.23+、Python 3.11+ 与现有前端。正式 core 仍按自己的 C++20 配置构建。控制面只用 Go 标准库，分析器和机制实验只用 Python 标准库。

在仓库根目录可以先跑不依赖服务的实验：

```powershell
python -m tutorials.labs --list
python -m tutorials.labs --case lifecycle-outbox
python -m tutorials.labs --all --json
python -m unittest discover -s tutorials/labs -t . -v
```

十二个 case 分别覆盖生命周期、调用树、支配关系、SSE、契约、工具权限、checkpoint、受控比较和证据。CLI 用实际断言裁决；`--json` 返回范围、观察值和检查清单，失败退出非零。各章还给出直接调用函数的实验、独立计算题和定向破坏练习。

Mini Drop 的 `smoke.py` 接受编译好的控制面、采集器、Python 和 analyzer 四个绝对路径，自建临时回环服务，运行真实采集、分析、重启与重试，并核对文件摘要。脚本关闭自己启动的进程，产物由指定输出收据保留。它与固定合成机制实验分别记录。

## 数据与结论的边界

Mini Drop 测量受控采集器自身的 CPU，`source=controlled_self`、`unit=cpu_ticks`。Windows 使用进程 CPU 计账，其他平台使用 `std::clock()`；平台和粒度不同，零计数是合法观测。结果中的两层树表达进程计账，没有采到业务函数栈。文件 journal、单 worker 和单 workdir 不提供 PostgreSQL 事务、多进程租约、远程 Agent 或生产鉴权。

机制实验全部使用固定合成输入。生命周期实验实际使用临时 SQLite 事务，但不证明 PostgreSQL 锁或真实网络恢复；诊断回放模型使用共享内存，不具备重启后的持久化；性能比较使用固定成本，没有测得真实加速或根因；网关不调用真实模型。教学 `LESSON_SELF_CPU_V2` 不注册到正式任务目录。正文将进一步接入生产的工作单独列出。

学习完成需要保留自己的来源、命令、版本、结果和局限。能预测一个坏实现会怎样失败，再实际观察到这条失败，通常比背出一个术语更能说明掌握程度。正式采集、PG、真实模型和线上语义验收仍以各自独立记录为准。
