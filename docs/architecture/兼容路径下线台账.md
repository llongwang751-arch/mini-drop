## 治理规则

- **Owner**：上表 Owner 列负责推动对应下线条件。
- **新增兼容路径**：必须在本台账登记 Owner / 引入原因 / 下线条件 / 最晚删除版本，否则拒绝合入。
- **使用指标**：下线前确认对应路径无生产流量（如 legacy 诊断无新请求、宽代理无命中）。
- **回滚保障**：每项下线保留一个可回滚的开关或显式提交点，删除前跑全量回归。
