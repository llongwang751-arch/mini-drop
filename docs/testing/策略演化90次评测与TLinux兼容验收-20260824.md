## 4. TLinux 2/3/4 兼容

### 4.1 已完成的工程修改

- 预检脚本不再加载完整 Agent，不安装 `grpc` 也能运行；
- 最低 Python 版本统一为 3.10，修复“声明支持 3.9，但源码使用 `X | None` 语法”的矛盾；
- Worker 安装脚本会检查 Python 3.10+；
- 心跳兼容信息增加 `tlinux_generation`；
- 预检支持覆盖 OS release、内核版本和架构，便于 CI 跑发行版矩阵；
- 增加 TLinux 2、3、4 夹具和采集器注册表漂移测试。

### 4.2 模拟矩阵结果

| 系统 | 识别代次 | 内核样例 | 架构 | 包管理器 | 结果 |
|---|---:|---|---|---|---|
| TLinux 2 | 2 | `5.4.241-tlinux` | x86_64 | yum | 通过 |
| TLinux 3 | 3 | `5.4.241-tlinux3` | x86_64 | dnf | 通过 |
| TLinux 4 | 4 | `6.6.90-tlinux4` | aarch64 | dnf | 通过 |

执行命令示例：

```powershell
python scripts/check_tlinux_compat.py --json `
  --os-release-file tests/fixtures/tlinux/tlinux2-os-release `
  --kernel-release 5.4.241-tlinux --architecture x86_64
```

### 4.3 当前云机真实预检

`47.112.10.137` 的实际环境是 Ubuntu 24.04.4、Linux 6.8、x86_64，不是 TLinux。预检成功识别：

- 可用：`perf_cpu`、`continuous_perf`、`go_pprof`、`memory_smaps`、`sys_metrics`；
- 不可用：`ebpf_io`、`java_async`、`pyspy`；
- tracefs、BTF、procfs 均存在。

因此当前能证明预检在真实 Linux 上可运行，不能证明 TLinux 2/3/4 的 perf、eBPF 和语言级采集器已经真机通过。最终认证仍需分别在三种 TLinux 主机运行：

```bash
python3 scripts/check_tlinux_compat.py --json
python3 scripts/check_tlinux_compat.py --require perf_cpu --require sys_metrics
```
