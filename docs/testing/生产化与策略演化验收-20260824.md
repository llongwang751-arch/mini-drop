- 正式 90 次故障 Campaign 已全部完成，唯一执行 ID 为 90，失败 0。
- 评分由保存的原始 Campaign 重建，不重新注入故障，也不读取预填结论。

## 证据重算

```powershell
python scripts/run_official_campaign.py `
  --output-dir reports/benchmark/official-90 `
  --rescore-existing
```

该命令只读取 `raw-campaigns/`，逐条重建提交和报告。若缺少任意原始 Campaign 会直接失败，不能用汇总文件绕过。

## 边界

- 本轮生产化测试验证代码路径，不替代云服务器长时间压力测试。
- 云端采集器能力要在新镜像部署后重新执行 preflight；容器安装工具并不代表宿主机内核一定开放 perf/BPF 权限。
- 策略演化的独立回放和长期对抗序列是可重复的确定性评测；云端真实故障触发后的策略激活仍需在部署完成后保留运行记录。
