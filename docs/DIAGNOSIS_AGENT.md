# Drop 诊断 Agent（20261020.3）

本页保留20261020.3历史交付。当前实现及自动复测、源码定位、隔离修复见[Agent V2](DIAGNOSIS_AGENT_V2.md)。

这次开发依据导师复刻文档的采集、分析、规则建议链路及测试开发 JD。它是当前仓库的扩展实现，不代表腾讯内部源码、内部规范认证或已投入腾讯业务使用。

用户从一个完整成功的任务进入“智能诊断”，输入具体问题。Go 服务绑定当前任务、采集 attempt、分析 job/run 与完整结果哈希，异步执行工具循环，保存证据，再生成可审阅的假设和验证步骤。C++ Agent 仍负责采集，Python Analyzer 仍负责解析和测量；模型不会接管这两个服务。

## 实际流程

1. 用户选择 AI 工具诊断，确认问题文本不含敏感信息，并同意发送问题与脱敏统计。
2. 服务先读取授权结果的脱敏摘要 E1。模型按问题调用受控工具，平台执行后以 tool 消息回填。
3. 必须检查热点及采集质量。模型可修改同一采集器的复测时长和频率，生成草案。
4. 报告必须通过 JSON 结构、长度、实际证据引用和必要工具校验，展示“待验证假设”和验收方法。未经校验的报告不落为成功。
5. 用户审阅原任务目标和复测草案，再单独确认创建新任务。平台重新验证权限、在线状态、能力、TaskKind schema 和进程身份；模型不能直接执行。
6. 新采集任务继续走原有 C++ → 对象存储 → Python Analyzer 链路。结果完成后通过已有对比页验证，业务 P95/P99、吞吐和错误率仍需现场补齐。

未配置模型或不希望出站时，可以使用“本地证据检查”。此模式执行确定性工具流程，明确显示无模型调用，不冒充 AI 推理。

## 工具与数据边界

| 工具 | 输入/输出 | 权限和限制 |
| --- | --- | --- |
| read_profile_summary | 固定任务的数值、Top20 哈希符号摘要 | 不接受目标、路径、URL、SQL 或命令 |
| inspect_hotspots | Top10 self/total 比例、rank、哈希符号和固定枚举语义线索 | 线索由本地符号词形分类产生，不等于已证明锁等待、GC 压力或缺陷 |
| check_collection_quality | 白名单采集参数、导入来源、短窗口及未知指标 | 不发送 PID、主机、原符号、原始文件、业务身份 |
| inspect_call_paths | 按热点 rank 展开有限调用者、被调用者及出现位置 | 8MiB输入预算、4096节点、64层深度；明确是否截断；PROC_CPU线程计数不冒充函数栈 |
| propose_verification | 可定制同类采集的时长和频率；输出受 schema 校验的草案 | 时长最多60秒、频率最多999Hz；不切换任意采集器，不执行 shell；导入数据要求人工复测导入 |

平台内原符号只在授权页面显示，与模型看到的 rank 对照。模型只能给函数/热点层面的定位线索；没有源码映射、业务指标和重复测量时不能承诺源码行号、已确认根因或优化收益。样本权重不能当作请求延迟、CPU 利用率或回退幅度，导入权重的单位未知时也不能当作耗时。

模型调用使用服务端配置的可信 HTTPS chat-completions 端点和 secret 文件。当前联调模型为实际账号返回的 deepseek-flash。请求包含 thinking.type=disabled，使用非流式 tool_calls；保存的是工具观测和结构化报告，不保存或展示隐藏思维链。模型密钥不进源码、浏览器、日志、制品或证据。

每次执行最多4轮模型、8次工具、150秒，单次 HTTP 最多30秒（实际 provider 测试独立35秒客户端）、响应64KiB，单工具输出16KiB。每用户最多3个活跃诊断；单 worker 串行出站。工作租约180秒，崩溃后最多3次执行；因此故障恢复可能重复只读模型调用，不能宣称计费恰好一次。取消立即禁止后续落库及复测，正在进行的上游请求可能到响应或超时后才退出。

## 工程约束

- SQL 006 为增量建表；原 protobuf、TaskKind 字段及采集/分析状态不变。API 最低 schema 为6，旧版本镜像保留。
- 请求通过 Idempotency-Key 去重；相同键不同输入返回409。失败后的新诊断使用新键，保留原失败记录。
- 状态、trace 及 task_events 在事务内提交；每次工具提交与最终提交均复核用户授权、当前采集和分析版本、输入哈希及租约所有权。
- 复测创建与来源事件在同一事务内提交，并锁住原任务以防并发重分析；复测仍复用任务创建的幂等机制。
- 未知工具、越界参数、额外字段、尾随 JSON、虚构证据编号、HTML/链接报告、截断/超限/上游异常均拒绝，不回传供应商原始错误。
- 用户问题和证据均视作不可信数据。提示词约束与服务端工具白名单共同限制行为；不声称可以从理论上杜绝所有模型幻觉。

## 配置与部署

AI_ENDPOINT=https://api.deepseek.com/chat/completions，AI_MODEL=deepseek-flash；密钥仅写 deploy/secrets/ai_api_key，只读挂载到 API。用户已将目标变更为腾讯云82.157.81.79；该机使用独立txdrop项目和compose.tencent.yml，合并于基础、tools、helper、helper-ebpf、HTTPS及observability之后。旧主机的compose.release-20261020.yml候选未部署，不用于新机。启动前用新 API 镜像执行迁移；切换后验证 API readiness、模型配置状态、真实结果诊断及正常采集。保留生产数据卷与全部已命名镜像，禁止 down -v。
