## 本次实施

- `scripts/dev.py`：独立 Compose project、仅 loopback Web 端口、独立数据卷/凭据、前置检查、启动/停止/状态/日志；不挂宿主 PID、Docker socket 或生产 Secret。`web/scripts/dev-local.mjs` 提供选定本地后端的热更新入口。
- Web：借鉴暖白、墨色、橄榄绿与自托管字体；保留诊断信息密度、真实数据、双状态、火焰图、权限与失败证据。支持持久化的桌面紧凑导航，移动抽屉保留完整文字。
- Core：先关闭事件生产者，再触发异步退出并排空调用栈，避免采集停止时持续写入；该修复必须通过严格编译及真实采集验证后才能计为完成。

验证结果、失败和最终发布范围继续写入 DEVELOPMENT_LOG、DELIVERY_MATRIX 与独立发布证据，不用历史测试替代新源码验证。
