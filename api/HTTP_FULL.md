# 扩展 REST 契约 v2

所有路径以 `/api/v1` 为前缀，仍使用统一 envelope、字符串 ID、ISO8601 UTC、HttpOnly 会话、写请求 CSRF 与创建任务 Idempotency-Key。下列为本轮实现契约，验证结果另记开发日志。

- `POST /tasks` 保留原参数，同时接收 `group_id?:string,visibility?:'private'|'group',parameters:{pid?,duration_seconds?,frequency_hz?,scope?,target?,budget?,options?},import?:{filename:string,content_type:string,data_base64:string,format?:string,auxiliary?:[{filename,content_type,data_base64,format?}]}`。主文件与附件合计最多32MiB，HTTP体最多64MiB；离线导入明确写入params.source=import，清除现场PID、时长与频率，禁止Agent目标与导入混用。BOLT必须提供target.elf，GPERF/JEPROF可选；附件由TaskKind白名单限定。`collapsed_text`保留2MiB兼容。target/budget/options字段由TaskKind的JSON Schema 2020-12约束。只读traceparent由服务器注入，禁止客户端指定source/traceparent。
- `GET /auth/providers` → `{local:true,oidc:{enabled:boolean,name:string},ai:{enabled:boolean,name:'模型辅助诊断'}}`。仅返回开关和显示名称，无endpoint或secret。`GET /auth/oidc/start`发起浏览器跳转；`GET /auth/oidc/callback`完成后跳转`/`，前端继续`GET /auth/me`。OIDC只由服务器环境配置issuer/client/secret/redirect，启用时校验state、nonce、PKCE、issuer/audience/JWKS签名。新身份默认viewer。
- 角色保留`viewer/operator/admin`兼容，新增`group_admin/platform_admin`；`admin`是platform_admin兼容别名。成员角色`viewer/operator/group_admin`。`GET /groups` →分页列表，Group `{id,name,description,created_at}`；`POST /groups {name,description?}`仅平台管理员；`GET /groups/:id` →Group加`members:[{user_id,username,display_name,role}],agents:[{agent_id,permission:'read'|'operate'}]`；`PUT /groups/:id/members/:user_id {role}`和`DELETE`由该组管理员/平台管理员；`PUT /groups/:id/agents/:agent_id {permission}`及`DELETE`由本组管理员/平台管理员执行，组管理员只能委派自己已经拥有的Agent权限，不能把read提升为operate或访问未知Agent。
- `GET /tasks/:id/shares` →列表；`POST /tasks/:id/shares {user_id?:string,group_id?:string,permission:'read'|'operate'}`二选一主体；`DELETE /tasks/:id/shares/:share_id`。仅任务owner/所属组管理员/平台管理员管理共享。读授权统一覆盖详情、result、suggestions、events/SSE、artifacts；operate额外允许取消/重试。任务组成员仅在visibility=group时获得本组角色对应权限。
- 任务详情新增 `permissions:{read,operate,share,delete,reanalyze}`，均由同一授权规则计算，生命周期限制仍独立适用。`DELETE /tasks/:id`仅终态任务管理者软删除，保留历史/制品及其原保留期。`PATCH /users/:id {role?,display_name?,password?}`仅平台管理员，保护最后一个平台管理员，密码变更撤销该用户会话。`PATCH /agents/:id {enabled:boolean}`仅平台管理员，启停与审计同事务。`GET /agents/:id/events`和`/diagnostics?category=resources|capabilities|processes|events`执行相同Agent范围授权；诊断走有界gRPC FetchData。
- `POST /composites {name,group_id?,visibility?,deadline_seconds:1..3600,allow_partial_success:boolean,nodes:[{key:string,required:boolean,depends_on:string[],task:{name,kind,target_agent_id,parameters}}]}`需Idempotency-Key。最多16节点，禁止环、导入与嵌套。返回`{id,name,status,creator_id,group_id,visibility,deadline_at,allow_partial_success,created_at,updated_at,summary:{total,waiting,running,succeeded,failed,skipped},nodes:[{key,required,depends_on,status,task_id?,error_code?,task?,result?}]}`。GET `/composites`分页列表、GET `/composites/:id`详情、POST `/composites/:id/cancel`取消未完成子任务。状态`PENDING/RUNNING/SUCCESS/PARTIAL_SUCCESS/FAILED/CANCELED/TIMED_OUT`。
- Composite创建返回run；节点在GET详情提供。详情额外返回`report:{results:[{node_key,task_id,summary}],suggestions:[{node_key,task_id,suggestion}],limitations:[]}`。节点result为有界摘要，完整树到各子任务result查询；不同采样器权重不相加。整体期限独立于出站RPC重试循环检查。
- `POST /schedules`扩展`{name,cron?:'0 9 * * 1-5',interval_minutes?:number,timezone:'Asia/Shanghai',group_id?,visibility?,template:{...CreateTask}}`；cron与interval二选一，五段标准cron，IANA时区，模板不可修改。响应新增`cron`、`group_id`、`visibility`；原有启停/删除/records保留。records新增`template_snapshot`，唯一schedule_id+scheduled_at；错过的时点跳到下一未来时刻，避免重启补发风暴。
- `GET /rules`已登录可读，返回List；`PATCH /rules/:key {enabled?,severity?,min_samples?,threshold?,config?}`平台管理员。Rule `{key,enabled,severity,min_samples,threshold,config,version,updated_at}`。`POST /tasks/:id/suggestions/ai {consent:true}`需任务operate权限，返回202 AIRequest。外部AI仅发送数值与不可逆哈希符号TopN摘要，无原始profile/路径/Agent标识；配置缺失返回AI_UNAVAILABLE。建议保留`engine,version,input_digest`，置信度未校准会明确标注。
- 模型请求优先stream:true。SSE供应商逐块净化并在Task/current-attempt/AI-lease/当前授权fencing后保存`SUGGESTION_DELTA {text,ai_request_id,streamed:true}`；成功`SUGGESTION_CREATED`、失败`SUGGESTION_FAILED`均带ai_request_id。上游限制30秒、256KiB、256块、最终纯文本8KiB；非流供应商回退仅标streamed:false，不产生假增量。`GET /tasks/:id/suggestions/requests`返回持久请求状态List，刷新后可恢复。三个崩溃租约领取后仍不成功即明确失败。
- `POST /tasks/:id/reanalyze`仅平台管理员，当前采集须COLLECTED且job为success/failed；保留analysis_job_runs历史和旧建议、递增后续run编号，重新入队并清当前result。pending/running/retry均拒绝，不覆盖旧running lease。
- `POST /tasks/:id/suggestions/:suggestion_id/feedback {rating:'useful'|'not_useful',comment?:string}`，每用户/建议upsert；GET同路径返回授权用户反馈列表。评论最多1000字节，建议内容仅纯文本，前端禁止unsafe HTML。
- Artifact增加`format,metadata,expires_at,retention_class,download_allowed`；过期、非ready、禁止下载时不给签名URL，过期返回410。保留期为RAW14天/INTERMEDIATE3天/RESULT90天/LOG14天/MANIFEST90天；URL时长不超过5分钟或剩余保留期。真实对象删除与对账由独立maintenance服务负责。下载继续逐次授权与审计。
- `POST /client-errors {code:'FLAME_LAYOUT_FAILED'|'WEB_RENDER_FAILED'}`登录+CSRF+共享写限流，仅接受固定错误码，不接收message/path/profile/stack，递增`drop_web_errors_total{code}`。HTTP请求直方图、gRPC客户端指标、实际SQL队列/租约/Agent/保留期gauge通过内网`/metrics`暴露。

用户/任务/Agent/计划查询均执行数据库资源范围过滤。数据库共享限流替代进程内限流，多个API副本共享计数；同一用户的创建配额继续由事务锁保证。

当前实际查询边界：Agents最多从数据库取500条后过滤/分页；Events每批500条，Agent events/计划records/feedback最新100条，AI requests最新50条，Composite runs最新100条，Users最多200条。Groups和Schedules目前没有数据库分页限制、返回全部授权行，List中的page=1/page_size为返回数。Agent diagnostics的processes/events请求上限100、直接返回数组，resources/capabilities返回对象；HTTP当前未透传Core generated_at/truncated元信息，不能视为完整主机清单。

完整60项HTTP操作与Schema见`../docs/openapi.yaml`，生成器`tools/sync_openapi.py`复制共享TaskKind参数Schema，检查器`tools/check_http_contract.py`核对实际Gin路由/公共DTO/CSRF/幂等和严格输入边界。静态契约检查不能替代真实联调。

部署配置：OIDC_ISSUER/OIDC_CLIENT_ID/OIDC_CLIENT_SECRET[_FILE]/OIDC_REDIRECT_URL；AI_ENDPOINT/AI_API_KEY[_FILE]/AI_MODEL；OTEL_EXPORTER_OTLP_ENDPOINT（OTLP HTTP，根路径自动补/v1/traces）。OIDC_ALLOW_HTTP/AI_ALLOW_HTTP只在明确的受控测试环境启用，缺省false。未配置IdP/模型时明确禁用，并保留本地登录/规则路径。迁移命令按文件名顺序执行全部SQL，运行时要求version2存在，兼容后续独立维护迁移。
