# Drop 视觉与交互规范

此文件记录用户确认的“浅色精密仪表台”方向。ui-ux-pro-max用于交互和可访问性检查，视觉建议按诊断产品实际用途取舍；样式位于 `web/src/styles.css` 与 `web/src/styles/`，本轮截图与浏览器验收见 `docs/evidence/upgrade-20261019/`。

## 视觉方向

浅色画布、浅色导航、墨色操作重点与橄榄绿选中态和暖色火焰图。总览以真实诊断记录为主，统计横带为辅；节点健康与任务队列形成右侧信息栏。登录页用原创SVG层叠切面组成Drop图形，不表示采样数据。采用较大中文标题、14px主体文字、12px辅助信息，紧凑元数据最低11px。

## 动效与输入

- 操作反馈采用短时色彩、边框和位移动效；文字入场保持不透明，避免动画期间降低可读性。尊重 `prefers-reduced-motion`。
- 表单具备可访问名称、错误反馈、提交等待和禁用态。网络故障保留逻辑提交幂等键，重试可恢复。
- 可见焦点、跳转主内容链接、移动菜单焦点循环和关闭后焦点返回。关闭的移动侧栏使用inert。
- `/` 或 Ctrl/Cmd+K聚焦任务搜索，`n` 创建诊断，Escape关闭菜单/弹窗；文本编辑和系统组合键优先。
- 火焰图搜索全量结果；Enter聚焦、方向键浏览、重置/展开。只为大图可视行生成SVG矩形，保留完整Worker布局，避免将数万节点全部加入Tab顺序。
- 数据等待、空状态、错误、无可用采样能力和无规则命中均有真实提示，不提供虚构指标或结果。
