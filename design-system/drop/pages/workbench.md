# Drop 诊断工作台设计约定

面向工程师的诊断产品，采用用户确认的浅色精密仪表台。浅色画布、浅色导航、墨色操作重点、橄榄绿选中态，保留火焰图的暖色数据编码；用真实任务建立信息层级。

颜色与字号以 MASTER 和 workspace.css 为准；绿色表示在线/成功，红色表示失败。辅助文字 #686d5e 在浅色画布上通过对比度检查。

字体自托管Manrope Variable + Bricolage Grotesque（品牌）+ IBM Plex Mono，中文使用平台sans-serif。采用4/8px间距；侧栏236px，可收起为84px并保存偏好，窄屏改抽屉，短屏可内部滚动。移动触控44px；手机任务显示记录布局，其他长表和火焰图可在自身容器浏览。

动效180–240ms仅限页面进入、hover、modal、状态更新；prefers-reduced-motion时关闭。所有图表必须显示真实数据；空态提供明确操作。禁止捏造趋势、成功率或伪造Agent。
