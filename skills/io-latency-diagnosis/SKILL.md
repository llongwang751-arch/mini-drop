# I/O 延迟分层诊断

## 适用场景

服务响应变慢并伴随磁盘写入、I/O 等待或文件系统延迟异常。

## 取证顺序

1. 比较系统吞吐、I/O 等待和设备延迟的基线与故障窗口。
2. 采集目标进程读写量、文件描述符和阻塞状态。
3. 使用 eBPF 或受控内核探针查看 I/O 延迟分布。
4. 停止受控写入故障并采集恢复窗口，确认指标回落。

## 结论门槛

- 进程写入量和内核延迟至少要有一项能与故障时间对齐。
- 设备繁忙但目标进程无写入时，应考虑噪声邻居，不归因于目标代码。
- tracefs 或 BPF 权限不可用时必须显式降级，不能生成伪造的内核证据。

## 安全边界

只使用白名单探针和受控故障开关；任何故障注入都必须在 finally 阶段恢复。
